# Definition of Done

Una historia se considera terminada cuando cumple todos los puntos aplicables:

- La historia y sus criterios de aceptación están identificados en el backlog.
- El cambio está implementado en una rama con nombre relacionado con la historia.
- La funcionalidad principal puede ejecutarse en el entorno de demostración.
- Existe al menos una prueba automatizada relevante.
- `npm run typecheck`, `npm run lint` y `npm run build` terminan correctamente.
- `npm run test:coverage` termina correctamente con PostgreSQL disponible.
- El cambio fue revisado mediante Pull Request o revisión equivalente registrada.
- No se incorporan secretos al repositorio.
- La guía de ejecución y la evidencia de la demostración están actualizadas.
- El Product Owner puede explicar el valor entregado y los criterios cumplidos.

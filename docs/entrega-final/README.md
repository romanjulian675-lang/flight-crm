El proyecto existente se conservará como punto de partida. Las mejoras realizadas durante la entrega se identificarán con historias de usuario, commits, pruebas y resultados verificables.

## Comandos de demostración

```powershell
npm run db:local
npm run db:migrate
npm run db:seed
npm run db:demo-history
npm run dev
```

En otra terminal:

```powershell
npm run verify:demo
```

## Regla de evidencia

Cada afirmación sobre usuarios, validación, reuniones o resultados debe estar respaldada por una captura, enlace, commit, ejecución registrada o nota fechada. Los elementos pendientes están marcados explícitamente y no deben presentarse como realizados hasta contar con evidencia.
